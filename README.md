# Financial Data Analysis & Dashboard (Power BI)

## 📌 Overview
This project focuses on analyzing global financial data to evaluate key sales performance metrics, regional profitability, and segment breakdowns[cite: 3, 4].

## 📊 Key Insights & Highlights
- **Total Sales:** $118.7M[cite: 3]
- **Total Profit:** $16.9M[cite: 3]
- **Profit Margin:** 14.23%[cite: 3]
- **Segment Analysis:** Detailed profit distribution across Government (65.04%), Small Business (23.66%), and Enterprise sectors[cite: 3, 4].
- **Geographic Analysis:** Country-wise profitability mapping highlighting performance across North America and Europe[cite: 4].

## 🛠️ Tools & Technologies Used
- **Data Visualization:** Power BI[cite: 1, 3]
- **Data Cleaning & Modeling:** DAX, Power Query, Excel[cite: 1, 2]
